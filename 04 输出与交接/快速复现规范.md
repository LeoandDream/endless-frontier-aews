# 快速复现规范

> AEWS v0.2.0 · Normative Specification

下游 Execution Agent 的快速复现是成功交付的最小可执行验证路径，不等于完整重建环境。Generator 只能在 Artifact 中要求该路径，不得把它表示为已经执行。

必须写明：

- 当前版本或 Commit；
- 工作目录；
- 最小环境要求；
- 输入、配置或数据位置；
- 一条或一组可执行命令；
- 预期输出；
- 验证标准；
- 失败时应查看的日志和状态。

快速复现不能省略关键参数，也不能把“打开文件看看”作为没有客观标准的验证。若结果依赖视觉或用户判断，必须明确用户验收步骤。
