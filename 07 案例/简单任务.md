# 案例 A：简单任务

## 用户请求

“把 README 中过时的安装命令更新为当前项目使用的命令，改完后检查链接。”

## Generator 输出

默认输出 `TASK_PROMPT.md`，而不是当前 AEWS Generator 直接修改 README。Prompt 指定下游 Execution Agent 在目标项目中检查 README、项目配置、脚本和 Git 状态后完成局部更新与链接验证。

## Generator 必要上下文

Generator 只需确认用户目标、已提供的项目入口和需要下游检查的 Context Source；如果当前项目现场不可可靠访问，就把 README、配置、脚本和 Git 状态列为下游 `Context to Inspect`，而不是假装已核验。

## Requirement READY / Artifact

- Goal：更新过时命令。
- Deliverables：README 修改、链接检查结果。
- In Scope：相关 README 命令和链接。
- Out of Scope：不改构建脚本、不升级依赖。
- Acceptance Criteria：命令与当前项目入口一致；本地链接检查通过。
- Verification：读取 diff，执行链接检查。

## 下游执行和验证

下游 Execution Agent 选择局部编辑，不需要询问命名或文件组织。修改后检查 diff，并运行链接检查。若所有条件通过，状态为 COMPLETED；交付修改摘要、验证结果和复现信息。Generator 的状态仅为 ARTIFACT_READY。

## 展示的工作方式

这是一个不需要复杂子任务的单任务。实现细节自主处理，但目标、范围和验收直接保留。
