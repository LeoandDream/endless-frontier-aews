# 案例 C：未完成任务

## 用户请求

“运行实验并比较两个模型的成功率，完成后给我结论。”

## 下游执行过程

下游 Execution Agent 检查了代码、配置、数据版本和评测脚本，完成了环境准备，但运行所需的服务器在执行期间不可用。AEWS Generator 的职责是根据这些信息生成续接 Artifact。

## 正确状态

状态为 BLOCKED，而不是 FAILED。原因是任务目标仍然明确，当前失败来自外部环境，未来条件满足后可以继续。

## Continuation Guide 必须记录

- Goal：比较两个模型的成功率；
- 已完成：环境检查、配置检查和评测命令准备；
- 未完成：实际运行和结果统计；
- 阻塞：服务器不可用；
- 已尝试：命令、时间、错误输出；
- 恢复条件：服务器恢复并确认数据挂载；
- 下一步：运行评测、保存日志、统计结果、检查显著性并生成报告。

## Continue Prompt Artifact

新的 Agent 应先读取当前配置、错误日志和 Continuation Guide，再检查服务器和数据状态。不得把没有运行结果的预期结论写成实验结论。
